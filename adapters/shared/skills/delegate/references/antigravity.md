# Antigravity delegation

When the `invoke_subagent` tool is surfaced, call it with the target `TypeName` and
put the filled template in `Prompt`. Do not try to override the model; Antigravity
currently runs subagents on the parent session model.
If no native spawn mechanism is surfaced, use ORCHESTRATION.md degraded mode: paste
the filled template into a fresh session and record the limitation.
