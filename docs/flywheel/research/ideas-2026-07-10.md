# Consulting note — five new feature/research ideas (2026-07-10)

Coordinator consulting session output. Read with `docs/flywheel/research/strategy-2026-07.md`
(differentiation ranking 1–3; none of these is vendor-absorbable plumbing per A5).
Ledgered as issues i4–i8. None started; prioritize via the improve pass / CEO queue.

## I-A. Fabrication linter (differentiator #1) — issue i4

Extend FACTS.md from ledger to enforcement: a script greps reports/docs/commits for
fact-shaped claims (model IDs, versions, counts, prices) and cross-checks them against
FACTS.md + producing commands. Claim without a source = warning. Minimal start: a
check.sh rule that any `claude-*` / `gpt-*` string outside `flywheel/config.json` and
`flywheel/FACTS.md` must match a FACTS row. No competitor has this.

## I-B. Compliance half-life telemetry (A1 evidence) — issue i5

A1 asserts prose-rule compliance decays; measure it instead of believing it. Add
per-session violation counts (delegations missing acceptance criteria, self-graded
completions, unlogged escalations) to `activity.json` via hooks; plot the trend on the
dashboard. Doubles as positioning content ("we measured policy decay in LLM sessions").

## I-C. Benchmark: same task with vs. without flywheel — issue i6

"Policies compound" has zero numbers behind it. Fixed task set (e.g., 3 repos seeded
with traps: a stale fact, a subtle bug, an oversized file); run a bare adapter session
vs. a flywheel-installed one; count fabrications and false completion claims. Even
n=5 gives README a measured delta. Feeds the real-world adoption test (STATUS #2).

## I-D. Rule provenance — citations for policy (A4 executable) — issue i7

Every rule line gets a decision/lesson ID (`[d3]`, `[L2]`). A rule nobody can cite a
reason for = deletion candidate, making delete-to-add executable instead of vibes.
Cheap: annotation convention + check.sh warning on uncited new rules.

## I-E. LESSONS auto-harvest (improve-loop input) — issue i8

Manual escalation logging demonstrably fails (LESSONS.md: 4 lines after 7 sessions).
A PostToolUse hook detects escalation signatures in `spawns.json` (same task, tier
change, retry) and drafts LESSONS lines for the coordinator to confirm at wrapup.

## Recommended order

I-A + I-B first (both make "policies compound" mechanically true and feed I-C's
benchmark story); I-D is the cheapest single win.
